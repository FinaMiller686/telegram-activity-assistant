# 项目来源

基于 [fr0der1c/tgtldr](https://github.com/fr0der1c/tgtldr) 的 `88e98fc`（2026-10-14）版本修改。

保留了上游的 Telegram 登录、PostgreSQL、凭据加密、网页登录和消息回补。新增活动提取、去重、编辑／删除处理、私人 Bot 按钮、提醒和日历导出。原来的群组摘要和快速回顾入口已关闭，日常使用活动助手。

选择它作为基础，是因为已有的登录、数据库和网页可以继续使用。其他两个候选项目没有做同等实测。

沿用 [PolyForm Noncommercial 1.0.0](../../LICENSE)，保留原版权声明。商业使用需要另行授权，这不是 OSI 认定的开源许可证。

外部模型只接收所选群组的文字和必要时间信息，图片文件不上传。登录信息和密钥加密保存；消息和活动数据库依赖部署磁盘的保护。Bot 仅限本人私聊，不在群里发言。安装和数据存放见[使用说明](../../使用说明.md)，测试情况见[测试说明](TESTS.md)。
