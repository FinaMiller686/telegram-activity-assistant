# Telegram 活动助手

[简体中文](RELEASE.md) | [English](RELEASE.en.md)

选好群以后，助手会把活动通知整理成中文，通过你自己的 Bot 发给你。

在消息里可以标记参加、稍后决定或已报名，点开原消息，也可以导出到 Apple 日历、Google Calendar 或 Outlook。网页里能查看活动列表、报名截止和时间冲突。

[Mac 安装步骤](../README.md#在-mac-上安装) · [Windows 安装步骤](WINDOWS.md) · [使用说明](../使用说明.md)

Windows 还没有做实机安装测试；图片识别也还没做。
