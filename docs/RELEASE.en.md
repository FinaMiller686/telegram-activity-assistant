# Telegram Activity Assistant

[简体中文](RELEASE.md) | [English](RELEASE.en.md)

Choose the groups you follow and receive their event notices as Chinese cards in a private Bot.

Save events you want to attend, mark registrations, or decide later. Open the original message, add an event to Apple Calendar, Google Calendar, or Outlook, and check deadlines and time conflicts on the website.

[macOS setup](../README.en.md#macos) · [Windows setup](WINDOWS.en.md) · [User guide](USAGE.en.md)

Windows has not had a real-device installation test yet. Image recognition is not implemented.
